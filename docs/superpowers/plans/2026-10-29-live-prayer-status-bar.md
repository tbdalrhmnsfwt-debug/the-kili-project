# Live Prayer Status Bar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add an ongoing, silent prayer notification whose countdown is rendered by Android's own chronometer and re-targeted at each prayer boundary — even with the app closed — and harden the existing in-app one-second clock against timezone and resume edges.

**Architecture:** Dart already computes the eight-day prayer window for the adhan scheduler. That same pass now also produces a sorted list of future prayer boundaries (name, absolute instant, local hour/minute) and hands it through a small MethodChannel to a Kotlin bridge. Kotlin stores the list, posts one `ongoing` low-importance notification whose chronometer targets the first boundary, and schedules one exact alarm per boundary with unique request codes. A broadcast receiver re-arms on reboot, app upgrade and clock/timezone changes.

**Tech Stack:** Flutter 3.x / Dart 3.5+, Riverpod 2.5.1, `adhan_dart` 2.0.1, `flutter_local_notifications` 17.2.4 (unused for the bar), Android Kotlin (`NotificationCompat`, `AlarmManager`, `BroadcastReceiver`, `MethodChannel`), `flutter_test` in CI, local ARM64 Dart for `dart analyze`/`dart format` only.

**Spec:** `docs/superpowers/specs/2026-10-29-live-prayer-status-bar-design.md`

## Global Constraints

- No new pub dependency and no new permission. The bar uses the existing `POST_NOTIFICATIONS`, `SCHEDULE_EXACT_ALARM`/`USE_EXACT_ALARM` and `RECEIVE_BOOT_COMPLETED`.
- Do **not** change `prayerClockProvider`. It is already a one-second aligned `StreamProvider.autoDispose` and `test/prayer_clock_test.dart` pins its cancellation. The "static" report is answered by the system surface, not by rewriting the in-app clock.
- MethodChannel name `zaker/prayer_status`; methods `sync`, `cancel`, `takeLaunchRoute`; native-to-Dart callback `openRoute`.
- Notification id `9000` (outside 3999 and the 4000–8999 ranges), channel id `zaker_prayer_status`, `IMPORTANCE_LOW`, no sound, no vibration, no badge. Alarm request codes `9100 + index`; content-intent request code `9200`.
- The bar is shown only when `enabled && statusBarEnabled && location != null && notificationsAllowed` — one pure predicate, `shouldShowPrayerStatusBar`.
- Exact copy, verbatim: settings title «شريط المواقيت الدائم», settings subtitle «يعرض الصلاة القادمة والعد التنازلي في شريط الإشعارات، حتى والتطبيق مقفول.», notification title «الصلاة القادمة: <الاسم>», notification text «<h:mm> ص|م • <المدينة>», public title «رفيق الطالب», public text «مواقيت الصلاة», channel name «شريط مواقيت الصلاة», diagnostics note as given in Task 7.
- The committed manifest documents `minSdk 32`, but Gradle is generated by `flutter create` in CI, so no Kotlin code may rely on it. Guard `NotificationChannel` with API 26+ and `setChronometerCountDown` with API 24+. Exact-alarm fallback: `AlarmManager.canScheduleExactAlarms()` on API 31+, else `setAndAllowWhileIdle`.
- Prayer names come from `PrayerNameInfo.label` («الفجر», «الظهر», «العصر», «المغرب», «العشاء»). Clock text uses Western digits with a `ص`/`م` suffix, matching `prayer_pill.dart`.
- Every user-visible string is Arabic and wrapped in `TrText` (diagnostics) or produced natively (notification). No new translation-table entry is added by this plan.
- `flutter test` and `flutter analyze` run only in CI. Locally, `/data/data/com.termux/files/home/the-kili-project/work/dartsdk/dart-sdk/bin/dart` runs `dart analyze` and `dart format` only. No task may claim a test result that CI did not produce.
- Format only the files a task touches (`dart format <paths>`), never `lib test`.
- Each task ends with `dart analyze` clean on the touched paths, a commit, a push, and the CI run for that sha read and recorded. Kotlin changes are verified only by the APK build and the Task 7 device checklist; there is no Kotlin test harness in this repository.

## Review Focus

1. **A boundary exactly at `now`, or inside the five-second lead.** The bar and the in-app card must skip a prayer whose instant has arrived instead of counting down to the past. Pinned by `test/prayer_status_schedule_test.dart` (lead-window case, Task 1) and `test/prayer_day_boundaries_test.dart` (exact-second case, Task 2).
2. **After Isha, before midnight.** The next target must be tomorrow's Fajr with its absolute instant, not "none" and not yesterday's Isha. Pinned in Task 1 (boundary list) and Task 2 (`PrayerDay.previousTime == ishaBefore`).
3. **A timezone change that keeps the same calendar date.** The cached `PrayerTimes` must recompute and the bar's displayed time must follow the new local clock. Pinned by `prayer_day_key_test.dart` (Task 2); device check in Task 7.
4. **Bar gating.** Master switch off, bar switch off, no location, and notifications denied must each clear the notification *and* every alarm. Pinned by the `shouldShowPrayerStatusBar` test (Task 1) and the scheduler's cancel path (Task 6); device checks in Task 7.
5. **Reboot, app upgrade and clock change.** The bar must come back with the correct target without the UI opening. There is no automated harness for a Kotlin broadcast receiver; the contract is pinned by the "only future boundaries" test (Task 1), the build in Task 5, and the reboot entry in the Task 7 device checklist.

```dart
const Duration kPrayerStatusLead = Duration(seconds: 5);

@immutable
class PrayerStatusBoundary {
  const PrayerStatusBoundary({
    required this.at,
    required this.name,
    required this.hour,
    required this.minute,
  });

  final DateTime at;
  final String name;
  final int hour;
  final int minute;

  Map<String, Object?> toJson() => {
        'at': at.millisecondsSinceEpoch,
        'name': name,
        'hour': hour,
        'minute': minute,
      };
}

List<PrayerStatusBoundary> buildPrayerStatusBoundaries({
  required Iterable<PrayerTimes> days,
  required DateTime now,
  Duration lead = kPrayerStatusLead,
}) {
  final cutoff = now.add(lead);
  final boundaries = <PrayerStatusBoundary>[];
  for (final times in days) {
    final moments = <PrayerName, DateTime>{
      PrayerName.fajr: times.fajr,
      PrayerName.dhuhr: times.dhuhr,
      PrayerName.asr: times.asr,
      PrayerName.maghrib: times.maghrib,
      PrayerName.isha: times.isha,
    };
    for (final entry in moments.entries) {
      final local = entry.value.toLocal();
      if (!local.isAfter(cutoff)) continue;
      boundaries.add(
        PrayerStatusBoundary(
          at: local,
          name: entry.key.label,
          hour: local.hour,
          minute: local.minute,
        ),
      );
    }
  }
  boundaries.sort((a, b) => a.at.compareTo(b.at));
  return List<PrayerStatusBoundary>.unmodifiable(boundaries);
}

bool shouldShowPrayerStatusBar({
  required bool adhanEnabled,
  required bool statusBarEnabled,
  required bool hasLocation,
  required bool notificationsAllowed,
}) =>
    adhanEnabled && statusBarEnabled && hasLocation && notificationsAllowed;
```

```dart
/// The ongoing system notification that counts down to the next prayer.
///
/// Android renders the countdown with its own chronometer, so the process may
/// be dead; this wrapper only hands the boundary list to the native bridge and
/// routes a tap back into the app. Every call is guarded: on a platform
/// without the bridge (tests, desktop) it silently reports failure.
library;

import 'package:flutter/foundation.dart';
import 'package:flutter/services.dart';

import '../features/prayer/prayer_status_schedule.dart';

class PrayerStatusBar {
  PrayerStatusBar._();

  static final PrayerStatusBar instance = PrayerStatusBar._();

  static const String channelName = 'zaker/prayer_status';
  static const MethodChannel _channel = MethodChannel(channelName);

  /// Called on the platform thread when the user taps the bar.
  void Function(String route)? onOpenRoute;

  bool _attached = false;

  /// Registers the native-to-Dart callback. Safe to call more than once.
  void attach() {
    if (_attached) return;
    _attached = true;
    _channel.setMethodCallHandler((call) async {
      if (call.method != 'openRoute') return null;
      final route = call.arguments;
      if (route is String) onOpenRoute?.call(route);
      return null;
    });
  }

  /// Stores [boundaries] natively, posts the bar and re-arms every alarm.
  Future<bool> sync({
    required String city,
    required List<PrayerStatusBoundary> boundaries,
  }) async {
    try {
      final ok = await _channel.invokeMethod<bool>('sync', <String, Object?>{
        'enabled': true,
        'city': city,
        'boundaries': [for (final boundary in boundaries) boundary.toJson()],
      });
      return ok ?? false;
    } on MissingPluginException {
      return false;
    } on PlatformException catch (error) {
      debugPrint('prayer_status: sync failed (${error.code})');
      return false;
    }
  }

  /// Hides the bar and cancels every boundary alarm.
  Future<void> cancel() async {
    try {
      await _channel.invokeMethod<void>('cancel');
    } on MissingPluginException {
      // No bridge on this platform.
    } on PlatformException catch (error) {
      debugPrint('prayer_status: cancel failed (${error.code})');
    }
  }

  /// The route the app was launched with, consumed once.
  Future<String?> takeLaunchRoute() async {
    try {
      return await _channel.invokeMethod<String>('takeLaunchRoute');
    } on MissingPluginException {
      return null;
    } on PlatformException {
      return null;
    }
  }
}
```

```kotlin
package com.zaker.zaker_ai

import android.app.AlarmManager
import android.app.NotificationChannel
import android.app.NotificationManager
import android.app.PendingIntent
import android.content.Context
import android.content.Intent
import android.os.Build
import androidx.core.app.NotificationCompat
import org.json.JSONArray
import org.json.JSONObject

object PrayerStatusBridge {
    const val CHANNEL = "zaker/prayer_status"
    const val ACTION_BOUNDARY = "com.zaker.zaker_ai.PRAYER_STATUS_BOUNDARY"

    private const val NOTIFICATION_ID = 9000
    private const val CHANNEL_ID = "zaker_prayer_status"
    private const val PREFS = "prayer_status_prefs"
    private const val KEY_PAYLOAD = "payload"
    private const val KEY_CITY = "city"
    private const val KEY_ALARMS = "alarm_count"
    private const val ALARM_REQUEST_BASE = 9100
    private const val CONTENT_REQUEST = 9200
    private const val MAX_ALARMS = 64
    private const val BOUNDARY_GRACE_MS = 2_000L

    fun sync(context: Context, arguments: Map<*, *>?): Boolean {
        val city = arguments?.get("city") as? String ?: ""
        val raw = arguments?.get("boundaries") as? List<*> ?: emptyList<Any?>()
        val now = System.currentTimeMillis()
        val boundaries = JSONArray()
        for (item in raw) {
            val map = item as? Map<*, *> ?: continue
            val at = (map["at"] as? Number)?.toLong() ?: continue
            if (at <= now) continue
            boundaries.put(
                JSONObject()
                    .put("at", at)
                    .put("name", map["name"] as? String ?: "")
                    .put("hour", (map["hour"] as? Number)?.toInt() ?: 0)
                    .put("minute", (map["minute"] as? Number)?.toInt() ?: 0),
            )
        }
        if (boundaries.length() == 0) {
            cancel(context)
            return false
        }
        val payload = JSONObject().put("city", city).put("boundaries", boundaries)
        prefs(context).edit()
            .putString(KEY_PAYLOAD, payload.toString())
            .putString(KEY_CITY, city)
            .apply()
        scheduleAlarms(context, boundaries)
        post(context, boundaries.getJSONObject(0))
        return true
    }

    fun cancel(context: Context) {
        prefs(context).edit().remove(KEY_PAYLOAD).remove(KEY_CITY).apply()
        cancelAlarms(context)
        notificationManager(context).cancel(NOTIFICATION_ID)
    }

    fun onBroadcast(context: Context, intent: Intent?) {
        val boundaries = readBoundaries(context)
        if (boundaries == null) {
            cancel(context)
            return
        }
        val now = System.currentTimeMillis()
        val lead = if (intent?.action == ACTION_BOUNDARY) BOUNDARY_GRACE_MS else 0L
        val index = nextIndex(boundaries, now, lead)
        if (index < 0) {
            cancel(context)
            return
        }
        scheduleAlarms(context, boundaries)
        post(context, boundaries.getJSONObject(index))
    }

    private fun post(context: Context, boundary: JSONObject) {
        ensureChannel(context)
        val city = prefs(context).getString(KEY_CITY, "") ?: ""
        val clock = clockText(boundary.getInt("hour"), boundary.getInt("minute"))
        val content = Intent(context, MainActivity::class.java)
            .putExtra("route", "/prayer")
            .addFlags(Intent.FLAG_ACTIVITY_SINGLE_TOP or Intent.FLAG_ACTIVITY_CLEAR_TOP)
        val contentIntent = PendingIntent.getActivity(
            context,
            CONTENT_REQUEST,
            content,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )
        val publicVersion = NotificationCompat.Builder(context, CHANNEL_ID)
            .setSmallIcon(R.drawable.ic_adhan_notification)
            .setContentTitle("رفيق الطالب")
            .setContentText("مواقيت الصلاة")
            .build()
        val builder = NotificationCompat.Builder(context, CHANNEL_ID)
            .setSmallIcon(R.drawable.ic_adhan_notification)
            .setContentTitle("الصلاة القادمة: ${boundary.getString("name")}")
            .setContentText("$clock • $city")
            .setContentIntent(contentIntent)
            .setOngoing(true)
            .setAutoCancel(false)
            .setOnlyAlertOnce(true)
            .setShowWhen(true)
            .setWhen(boundary.getLong("at"))
            .setUsesChronometer(true)
            .setVisibility(NotificationCompat.VISIBILITY_PRIVATE)
            .setPublicVersion(publicVersion)
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.N) {
            builder.setChronometerCountDown(true)
        }
        notificationManager(context).notify(NOTIFICATION_ID, builder.build())
    }

    private fun scheduleAlarms(context: Context, boundaries: JSONArray) {
        cancelAlarms(context)
        val manager = context.getSystemService(Context.ALARM_SERVICE) as AlarmManager
        val exact = Build.VERSION.SDK_INT < Build.VERSION_CODES.S ||
            manager.canScheduleExactAlarms()
        val now = System.currentTimeMillis()
        val count = minOf(boundaries.length(), MAX_ALARMS)
        for (i in 0 until count) {
            val at = boundaries.getJSONObject(i).getLong("at")
            if (at <= now) continue
            val pending = alarmIntent(context, i)
            if (exact) {
                manager.setExactAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, at, pending)
            } else {
                manager.setAndAllowWhileIdle(AlarmManager.RTC_WAKEUP, at, pending)
            }
        }
        prefs(context).edit().putInt(KEY_ALARMS, count).apply()
    }

    private fun cancelAlarms(context: Context) {
        val manager = context.getSystemService(Context.ALARM_SERVICE) as AlarmManager
        val count = prefs(context).getInt(KEY_ALARMS, 0)
        for (i in 0 until count) {
            val pending = alarmIntent(context, i)
            manager.cancel(pending)
            pending.cancel()
        }
        prefs(context).edit().putInt(KEY_ALARMS, 0).apply()
    }

    private fun alarmIntent(context: Context, index: Int): PendingIntent {
        val intent = Intent(context, PrayerStatusReceiver::class.java)
            .setAction(ACTION_BOUNDARY)
        return PendingIntent.getBroadcast(
            context,
            ALARM_REQUEST_BASE + index,
            intent,
            PendingIntent.FLAG_UPDATE_CURRENT or PendingIntent.FLAG_IMMUTABLE,
        )
    }

    private fun nextIndex(boundaries: JSONArray, now: Long, lead: Long): Int {
        for (i in 0 until boundaries.length()) {
            if (boundaries.getJSONObject(i).getLong("at") > now + lead) return i
        }
        return -1
    }

    private fun clockText(hour: Int, minute: Int): String {
        val suffix = if (hour < 12) "ص" else "م"
        val h = if (hour % 12 == 0) 12 else hour % 12
        return "$h:${minute.toString().padStart(2, '0')} $suffix"
    }

    private fun ensureChannel(context: Context) {
        if (Build.VERSION.SDK_INT < Build.VERSION_CODES.O) return
        val channel = NotificationChannel(
            CHANNEL_ID,
            "شريط مواقيت الصلاة",
            NotificationManager.IMPORTANCE_LOW,
        )
        channel.setSound(null, null)
        channel.enableVibration(false)
        channel.setShowBadge(false)
        notificationManager(context).createNotificationChannel(channel)
    }

    private fun readBoundaries(context: Context): JSONArray? {
        val raw = prefs(context).getString(KEY_PAYLOAD, null) ?: return null
        return try {
            JSONObject(raw).optJSONArray("boundaries")
        } catch (_: Exception) {
            null
        }
    }

    private fun prefs(context: Context) =
        context.getSharedPreferences(PREFS, Context.MODE_PRIVATE)

    private fun notificationManager(context: Context) =
        context.getSystemService(Context.NOTIFICATION_SERVICE) as NotificationManager
}
```
