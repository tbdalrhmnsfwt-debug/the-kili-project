# رفيق الطالب — «شنطتي» (My Bag) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the Phase 2 «شنطتي» stub into the real bag: a versioned local index of subject and custom folders, each with four pockets (PDFs, voice, boards, links), the home preview fed by the same controller, and the screens and routes the spec defines.

**Architecture:** Flutter-free models and a store under `lib/core/my_bag/` (models, atomic JSON index through `KeyValueStore`, per-folder media directories); a Riverpod controller that seeds one folder per subject of the selected grade and projects the preview list; screens under `lib/features/bag/`; the PDF, audio and image→PDF capabilities are reused from the existing channels and packages — no second recorder, player, or PDF writer.

**Tech Stack:** Flutter 3.x / Dart 3.13, Material 3, Riverpod 2.5.1 `StateNotifier`, go_router 14, hugeicons 1.2.0, `package:pdf` for image→PDF, `file_picker`, `image_picker`, `url_launcher`, `share_plus`, existing Kotlin channels `zaker/audio_recorder` and `zaker/audio_player`, `flutter_test` in CI, local ARM64 Dart for `dart analyze` only.

**Spec:** `docs/superpowers/specs/2026-10-27-rafiq-al-talib-rebrand-design.md` (§Architecture 163–208, §«شنطتي» — My Bag 383–513, §Localization 878–903, §Privacy 905–922, §Testing 924–970, §Phased delivery phase 3 1010–1012)

**Plan 3 of 7.** Phase 2 (home and shell) shipped through `6ff65c0`; its `bagFolderPreviewProvider` body (`const []`) and the list-only `MyBagScreen` are this plan's starting seam. Phase 4 (PDF annotation and reader) owns the editor; this plan only opens, tags, adds and removes library PDFs.

## Global Constraints

- No new pub dependency and no new network call. Available and already declared: `pdf`, `printing`, `file_picker`, `image_picker`, `url_launcher`, `share_plus`, `path_provider`, `path`, `shared_preferences`, `flutter_riverpod`, `go_router`.
- `lib/core/my_bag/my_bag_models.dart`, `my_bag_store.dart` and `image_pdf_builder.dart` import no `package:flutter`; they may import `dart:io`, `dart:convert`, `dart:typed_data` and `package:path`. The store receives a `KeyValueStore` and a `Directory`; it never reaches for `LocalStore` or `path_provider`.
- Arabic source string is the translation key: widgets use `TrText`; every new static string is added to `assets/i18n/en_extra.json` **only if it is absent from both `assets/i18n/en.json` and `assets/i18n/en_extra.json`** (check with `grep -F "\"<key>\"" assets/i18n/en*.json`). Interpolated copy uses `context.trf` with a `{0}`/`{1}` template that exists in the English tables.
- All colours come from `ZakerColors` / the active `ZakerPalette` / `ZakerFeatureAccents`; no literal hex in `lib/`. Cards use `ZakerRadius.card` (16 dp) and `ZakerShadows.card`; inner surfaces use `ZakerRadius.md` (14).
- Gold `#D4AF37` is never small text on white; `goldDeep` is the label token there, and `cardAccentOf(accent, theme)` turns an accent into readable text on a card.
- Every user-visible text gets `maxLines` + `TextOverflow.ellipsis` (or wraps by design, e.g. chips); horizontal groups use `Expanded` / `Wrap` / a scroller — never an unconstrained fixed-width `Row`. Touch targets are at least 48×48; icon-only controls carry tooltips.
- Bag data is app-private: the index in `KeyValueStore` under `my_bag_index`, media under `<application support>/my_bag/`. No title, URL, recording or PDF text is logged.
- Caps: 100 voice clips per folder, 15 minutes per clip (the native recorder enforces it), 200 board images per folder, 100 links per folder, 25 images per compile, 96 waveform samples per clip.
- Folder deletion deletes its own `my_bag/folders/<id>/` directory and never a PDF base file; removing a PDF only drops the reference.
- `flutter test` and `flutter analyze` run in CI. - Each task ends with `dart format` on the touched files only, `dart analyze lib test` clean, a commit, a push to `main`, and the CI run for that sha read and recorded.

## Review Focus

1. **Grade changed after folders exist.** A secondary-1 user adds a PDF to «الرياضيات», then switches grade: the folder and its PDF must still be reachable under «كل الصفوف», and re-seeding must not create a second «الرياضيات». Seeding is keyed on `subject:<gradeId>:<subjectKey>`, and a deleted seeded folder is remembered as hidden.
2. **A file vanished under the bag.** The OS clears app data or the user deletes a recording: the clip row stays with «الملف مش موجود» and a delete action; opening it must not throw.
3. **Microphone denied or storage full.** Recording shows a plain explanation with «افتح الإعدادات» on denial, and refuses to start below a small free-space floor instead of producing a 0-byte clip.
4. **A hostile or malformed link.** `javascript:`, `mailto:`, `file:`, a bare host and a URL with spaces are rejected at add time with an explanation; only `http`/`https` ever reach the launcher.
5. **Deleting a folder that owns PDFs.** The confirmation names the folder and states that recordings, board images and links are deleted while PDFs stay in the library, untagged; after confirming, the folder's directory is gone and every referenced PDF still opens.

- [ ] **Step 3: Implement the models**

Create `lib/core/my_bag/my_bag_models.dart` with the interfaces above. Decisions the signatures leave open:

- JSON is `{"version":1,"folders":[...]}`. A folder serialises as `id`, `name`, `gradeId`, `subjectKey`, `custom`, `color`, `icon`, `pdfIds`, `createdAt` (UTC ISO-8601). Parsing returns `null` unless `id`, `name`, `subjectKey`, `icon` are non-empty strings, `gradeId` is a string, `custom` is a `bool`, `color` is a `num`, `pdfIds` is a `List` (non-string members are skipped) and `createdAt` parses.
- `MyBagFolder.subject` sets `custom: false`, `pdfIds: const []`, `id: subjectFolderId(gradeId, subjectKey)` and `iconName: iconName ?? bagIconNameFor(subjectKey)`.
- `subjectFolderId` is `'subject:$gradeId:$subjectKey'`; `bagProgressKey` is `'$gradeId|$subjectKey'`.
- `bagIconNameFor` matches case-insensitively on the Arabic key, in this order, and returns the first hit: `رياض|جبر|حساب|هندسة` → `Math`; `فيزياء` → `Atom01`; `كيمياء` → `Chemistry01`; `أحياء|احياء|علوم` → `Microscope`; `عربي|عربية` → `BookOpen01`; `إنجليز|انجليز|english` → `Translate`; `فرنس|ألمان|المان|إيطالي|اسباني|إسباني|لغة` → `Languages`; `تاريخ` → `History`; `جغراف` → `Earth`; `فلسفة|نفس|اجتماع` → `Brain01`; `دين|إسلام|اسلام|قرآن|قران` → `Quran01`; `حاسب|كمبيوتر|تكنولوجيا|برمجة` → `Computer`; `فنون|رسم|موسيقى` → `Palette`; `رياضة` → `SportShoe`; otherwise `Folder01`.
- `toMetaJson` is `{'voice': [...], 'boards': [...]}`; `toLinksJson` is `{'links': [...]}`. `fromParts` accepts a `Map` or a JSON `String`, and an unreadable part yields that part only as empty.
- `recent` sorts voice + boards + links by `createdAtMs` descending; the board title is `''`.
- `downsampleWaveform`: when `amplitudes.length <= maxSamples`, scale each sample `(a / 32767 * 100).round().clamp(0, 100)`; otherwise split into `maxSamples` contiguous index buckets, average each bucket, then scale the same way. An empty list returns `const []`, and `maxSamples <= 0` returns `const []`.
- `validateBagLinkUrl` trims; returns `'الرابط فاضي.'` for empty, `'الرابط لازم يبدأ بـ http أو https.'` when the scheme is not `http`/`https`, `'الرابط مش كامل.'` when the host is empty, `'الرابط فيه مسافة.'` when the trimmed value contains whitespace, and `null` otherwise. `bagLinkHost` returns `Uri.tryParse(url)?.host` when non-empty, else the trimmed input.
- `moveItem` returns a copy; an out-of-range `from` returns the copy unchanged; `to` is clamped to the post-removal length. `PocketTotals.from` counts `pdfIds.length` per folder and `media[id]?.countFor(...)` with a missing entry treated as empty.

Future<Uint8List> buildImagePdf(List<String> imagePaths) async {
  final doc = pw.Document();
  var pages = 0;
  for (final path in imagePaths) {
    final file = File(path);
    if (!file.existsSync()) continue;
    final bytes = await file.readAsBytes();
    if (bytes.isEmpty) continue;
    doc.addPage(
      pw.Page(
        pageFormat: PdfPageFormat.a4,
        build: (context) => pw.Center(
          child: pw.Image(pw.MemoryImage(bytes), fit: pw.BoxFit.contain),
        ),
      ),
    );
    pages++;
  }
  if (pages == 0) throw ArgumentError.value(imagePaths, 'imagePaths', 'no readable image');
  return doc.save();
}
