# Official Study Library — Implementation Report

Target: existing `zaker_ai` / ذاكرلي Flutter app (Thakir Pro), school year
2026–2027. Everything below was added inside the existing project; no screen,
route, model field or feature was removed.

Date: 2026-10-24

## 1. Summary

The app now contains a verified official-book library for:

- Grade 10 / first secondary (general secondary system).
- Grade 12 general secondary, with the three tracks kept separate.
- Grade 12 Egyptian Baccalaureate with its four pathways; shared core rows have
  an empty track and are shown to every pathway.
- Grade 1–12 material already present in the school library remains untouched
  and is still reachable from the same screens.

The pipeline is: verified catalog row → validated download → SHA-256 →
page-numbered extraction (text layer or OCR) → grounded explanations,
summaries, revision sheets, definition/formula/step sheets, vocabulary,
flashcards, mind maps, quizzes and a study plan. Every generated artifact
points back to a real PDF page; nothing is invented when the source lacks the
answer.

Statuses used: `available`, `downloading`, `downloaded`, `failed`,
`needs_update`, `not_published`, `manual_review`. Extraction states:
`not_started`, `extracting`, `organizing`, `ready`, `needs_review`, `failed`.

`manual_review` rows keep their official URL for traceability but are never
downloaded automatically. `not_published` rows have no URL. No URL is guessed
or synthesised.

Allowed PDF hosts, enforced by `OfficialBookUrlPolicy`:

- `elearnningcontent.blob.core.windows.net` (the Ministry host is spelled with
  three `n`s; the policy matches the catalog exactly)
- `egyptianbaccalaureate.blob.core.windows.net`

The policy requires HTTPS, rejects user-info/credentials in the URL, rejects
look-alike hosts, and re-validates the final URL after redirects.

## 4. Download pipeline

`BookDownloadService`:

1. Validates the catalog URL with the allowlist.
2. Downloads to `<target>.part`; resumes with a Range request.
3. Re-validates the final URL after redirects.
4. Checks HTTP status, content type, size (≥ 512 bytes) and the `%PDF-`
   signature.
5. Uses `pdf_readability.dart` to confirm the document can be opened.
6. Computes SHA-256, then renames the temp file into place atomically.
7. Keeps the previous valid file until the new one is fully verified.
8. Records ETag / Last-Modified for later HEAD checks.
9. Retries with bounded backoff; supports cancellation and at most two
   concurrent downloads.

On controller start the queue resumes. A `.part` file and the last
checkpoint make a restart continue rather than restart. Weekly HEAD checks
mark `needs_update` without deleting the current file.

Deduplication:

- Same official URL: the second row points at the first row's verified file.
- Same SHA-256: the redundant copy is removed and the canonical file is kept.

The only deletion the pipeline performs is removing a byte-identical duplicate
that was just downloaded; a verified file is never removed automatically.

## 5. Extraction

`BookExtractor`:

- Reads one PDF page at a time through Syncfusion.
- Uses OCR only for pages below 24 characters of text, and only for `ar`/`en`
  (the bundled Tesseract data).
- Default OCR cap is 300 pages. Pages beyond the cap are counted, warned
  about, and the result is marked `needs_review`; it is never presented as a
  complete searchable book.
- Checkpoints every 10 pages keyed by SHA-256; resuming continues from the
  saved page.
- Removes repeated page headers, groups pages by unit/lesson headings, and
  falls back to labelled 8-page ranges when no heading is recognisable.
- Writes the extraction JSON and a manifest atomically.

Verified local-network facts (transport-level, before compaction):

- Official Grade 10 mathematics PDF: HTTP 200, PDF content type, `%PDF-1.3`,
  24.9 MB, `Content-MD5` matches the local MD5, SHA-256 computed, HTTP 206
  range request supported.
- The official Arabic and English Grade 10 mathematics books are image-only:
  0 pages with a text layer out of 121 and 123 pages. OCR is therefore
  mandatory for these files; the cap/status behaviour above is what keeps the
  UI honest.

## 6. Study features

### Lesson screen (`official_section_screen.dart`)

Tabs: text (pages with page numbers), explanation, summary/tools, study tools.
The source strip shows the book, edition, pages, OCR/fallback warnings, and
opens the original PDF.

### Grounded artifacts

All local generators are extractive:

- Explanation: quotes key sentences and terms with page citations.
- Summary: selects and quotes sentences, preserving book order.
- Revision sheet: key points, definitions, formulas and steps in one compact
  note, plus self-test questions built only from terms the book defines.
- Definitions, formulas, steps: pattern-based extraction with page citations.
- Vocabulary: English tokens found in the lesson, glossed only when the
  bundled dictionary (`assets/dictionary/words.json`) has the word; context
  and page are included. Hidden when the lesson has no glossable word.
- Flashcards: reveal-before-answer cards; "I knew this / Review again /
  Difficult" feed the spaced schedule (1, 3, 7, 14, 30 days; `again` returns
  in 10 minutes and resets the streak; `difficult` returns tomorrow).
- Mind map: pan/zoom, expand/collapse, page buttons with a 44 px minimum
  target, and an expandable outline fallback.
- Quiz: MCQ, true/false and short answer; deterministic shuffling; page
  sources; missing `correctIndex` is handled without crashing and never
  marks an arbitrary option correct.
- Study plan: 25-minute blocks from real sections, reviews at +1/+3 days,
  quiz at +7 days, deterministic ids, completion preserved when rebuilding,
  overdue open tasks rescheduled without erasing completed ones.

Optional AI explanation is clearly labelled as supplemental, sends only the
extracted passage, and falls back to the local explanation when the backend is
unavailable. No API key is stored in the client or committed.

## 9. Security and policy

- No secrets, tokens, private URLs or credentials in client code or committed
  files.
- Only official Ministry / Baccalaureate hosts and verified catalog URLs are
  used; no filename guessing.
- Downloads are limited to material published by the official source; the app
  does not redistribute paid third-party books.
- The downloader respects normal HTTP semantics and does not bypass auth,
  CAPTCHA, robots or access controls. Blocked rows are marked
  `manual_review` instead.
- Generated content is labelled local vs supplemental AI, with page citations.
- Corrupt or missing files are reported; verified files are preserved.
